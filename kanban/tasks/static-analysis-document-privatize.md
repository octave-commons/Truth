# Document and Privatize Undocumented Public Functions

> Parent spec: `kanban/tasks/static-analysis-structural-cleanup.md`
> Parent kanban: `kanban/tasks/static-analysis-structural-cleanup.md`

Add docstrings to the 81 undocumented public functions reported by `bin/analyze`, or mark truly internal helpers as `^:private`. Covers non-test source namespaces, DSL macros, and test fixture functions generated by DSL macros.

**Scope:**
- Docstring every public function in the namespaces listed in §1.5 of the parent spec.
- Add `^:private` to helpers that are only used inside their own namespace.
- Update DSL macros (`defcomponent`, `defevent`, etc.) to emit docstrings on generated test fixture vars if they do not already.
- Keep test helper functions public but documented as fixtures or DSL-generated API.

**Done when:**
- `bin/analyze` reports zero undocumented public functions.
- `clojure -M:test` is green, including `test/architecture_test.clj`.
- No public API is removed without a `^:deprecated` alias.
