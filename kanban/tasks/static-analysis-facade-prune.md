# Prune the facades to their live aliases

> Parent: `kanban/tasks/static-analysis-regression-2026-07-24.md`

The dominant category in the 353 `clojure-lsp/unused-public-var` findings is not
dead code, not private-candidates, and not vocabulary. It is **199 re-export
aliases** — surface generated by the *completed* namespace-split refactors
(`static-analysis-split-render.md`, `static-analysis-split-stellar-core.md`,
both `done`).

The pattern is uniform and is **not** keyword indirection or a lookup map — this
was checked:

- `src/infra/menu.clj:23` — `(def col-panel widgets/col-panel)`. All 8 `col-*`
  are plain aliases of live `infra.menu.widgets` vars. Only `col-bar` (`:22`) is
  consumed by the facade itself (`:50`).
- `src/infra/inspect.clj:91` — `(def solar-mass "…" fmt/solar-mass)`. All 8
  delegate to `infra.inspect.fmt`.

Counts by namespace: `src/infra/render.clj` 28 (including the three `asset-*`
renamed aliases at `:132,135,137`), `src/domain/planet_formation.clj` 18,
`src/domain/ecology.clj` 18, `src/law/field.clj` 16,
`src/law/mass_transfer.clj` 15, `src/domain/stellar/structure.clj` 12,
`src/infra/menu.clj` 8, `src/infra/inspect.clj` 8, plus the remainder.
`src/law/stellar.clj`'s 27 are handled separately by
`static-analysis-dissolve-law-stellar-facade.md`.

## Owner decision (2026-07-24)

**Prune every facade to its live aliases.** Delete each re-export with zero
callers; **keep the namespaces themselves**. They are heavily required
(`law.stellar` by 65 files, `infra.camera` by 21, `law.field` by 18,
`domain.em` by 16) — the namespace is alive, these particular aliases are not.

The alternative considered and rejected: keep the facades whole as documented
compatibility API and blanket-exclude them from the linter (keyed to the
`facade-namespaces` set at `dev/smell_report.clj:40`). Cheaper, but it preserves
~199 lines of pure indirection and — decisively — **keeps real dead code
hidden**.

## Why this matters beyond the warning count

The facade layer is actively **masking** dead code. `domain.em.field/external-field-at`
is never flagged only because `src/domain/em.clj` aliases it. Pruning the alias
makes the underlying deadness visible, which is how the seven `domain.em`
coupling vars were found (see
`static-analysis-unused-pending-convention.md` — those are
incomplete-not-abandoned and get a marker, not a delete).

## Constraints

- Deleting an alias is only safe if **no** consumer resolves it. Resolve aliases
  **per file** — the alias `law` maps to different namespaces in different files
  (`law.stellar` in some, `law.crater` in `voxel/carve.clj`). Never do a
  repo-wide text substitution.
- Some aliases are *renames*, not pass-throughs (`infra.render`'s `asset-*`
  alias `asset/program-id` etc. under a different name). Check before deleting.
- Do not delete an alias whose underlying var is itself flagged — that pair
  belongs to the `UNUSED-PENDING` card, not this one.

## Outcome (2026-07-25)

**179 dead re-export aliases deleted** across 19 facades; every facade namespace
still exists and compiles. `clojure-lsp` unused-public-vars: 353 → 0 overall.

### The prune had to ITERATE — facades are stacked

This card assumed one pass. It took a fixpoint loop, because pruning an outer facade
reveals that the namespace beneath it is *also* a facade:
`domain.planet-formation` → `domain.planet-formation.spec` → `.physics`/`.composition`/
`.orbit`. Same shape as the `law.stellar` double facade Wave 1 dissolved. Round 1
deleted 157, round 2 deleted 22 more (16 in `planet_formation/spec.clj` alone), round 3
found none.

### Guards used before deleting an alias

1. **No use inside its own file.** clojure-lsp flags in-file-only usage too, so a
   flagged alias is not necessarily unreachable. Caught `infra.render/material`'s
   13 apparent uses — though see the caveat below.
2. **Target not itself flagged.** An alias to an already-dead var belongs to the
   `UNUSED-PENDING` card, not this one. Zero hits, and that is *expected*: the alias
   is what keeps the target reachable, which is exactly the masking this card
   describes. The reveal came after deletion, and was triaged, not left dangling.
3. **Per-file alias resolution.** `:as` maps to different namespaces in different
   files; nothing was substituted repo-wide.

**Guard 1 has a hole worth recording:** when a facade alias shares its name with a
namespace alias in the same file, `material/draw-material!` reads as a use of the var
`material`. `infra.render/material` was dead and survived the first pass because of
it. Anything relying on that heuristic should discriminate `name/` from bare `name`.

### Cascade cleanup

Deleting aliases orphaned 8 requires (`domain.genesis`, `domain.hydro`,
`domain.integrator`, `infra.render` ×3, `law.mass-transfer` ×2). Removed. Four ns
forms needed paren repair where the dropped require line carried the closing parens.

### Runtime-safety check, since `lsp` only sees static references

- `clj-kondo` `:unresolved-symbol` is at `:error` and reports 0 — every static
  reference resolves.
- No `resolve` / `requiring-resolve` / `ns-resolve` of any pruned name exists in
  `src`/`dev`/`bench` (only `bench.clj`'s own `'run` lookups and `criterium`).
- All render/dev namespaces load clean.
- `clojure -M:test` → 879 / 15486 / 0 failures.

`clojure -M:run demo` (this card's live smoke) **could not be run**: `src/infra/main.clj`
does not exist in `HEAD` and the `:run` alias has dangled since commit `0a9343a`,
independent of this work. Recorded as an open item on the umbrella card.
