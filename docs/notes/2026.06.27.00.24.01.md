2. Volumetric fog — working prototype

Replaced the sprite splat with true ray-marched volumetric fog. Each frame bakes the SPH gas field into a 3D froxel texture (emission + density), then a fullscreen shader integrates the volume-rendering equation along each view ray, with in-scattering from stars/hot cores (shadow-marched) so the light fills and shafts through the cloud — exactly the effect you described.

It's wired into the live dev window (:volumetric? true by default), falls back to sprites when there's no gas, and is tunable (kappa/emissionScale/scatterScale, and the visual smoothing radius). All in infra.render + infra.dev.window.
