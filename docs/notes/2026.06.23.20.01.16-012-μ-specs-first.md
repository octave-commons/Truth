# continue

Picking up exactly where we left off — `defaggregate` and `defprojection` are the next unlocking layer. Without them, fast-forward and rewind both require replaying the full event log from tick 0, which is unusable at universe scale.

The contract is:

- **Projection** = a pure `[acc event] -> acc` fold over the ledger. Named, reusable, cacheable.
- **Aggregate** = a snapshot + a pointer to the ledger position it was materialized from. Snapshots can be checkpointed to nippy without touching the world atom.

## μ-specs first

```clojure
(ns domain.ecs.ledger-test
  (:require
    [clojure.test :refer [deftest is testing]]
    [domain.ecs.core :as ecs]
    [domain.ecs.event :as evt]
    [domain.ecs.dsl :refer [defcomponent defevent defreaction
                             defprojection defaggregate]]
    [domain.ecs.ledger :as ledger]))

;; ----- shared fixtures -------------------------------------------------------

(defcomponent hp     "Hit points."  :int)
(defcomponent alive? "Alive flag."  :boolean)

(defevent took-damage
  "Entity received damage."
  [:map [:amount :int]]
  {:entity-count 1})

(defevent died
  "Entity transitioned to dead."
  [:map [:cause :keyword]]
  {:entity-count 1})

;; ----- projection μ-specs ---------------------------------------------------

(defprojection total-damage-dealt
  "Running sum of damage dealt across all took-damage events."
  took-damage
  {:init 0}
  [acc event]
  (+ acc (get-in event [:payload :amount])))

(deftest projection-folds-events
  (testing "projection accumulates incrementally"
    (let [world  (-> (ecs/empty-world)
                     evt/with-ledger)
          [world e1] (ecs/spawn world)
          world  (evt/dispatch world (->took-damage 1 #{e1} {:amount 30}))
          world  (evt/dispatch world (->took-damage 2 #{e1} {:amount 20}))
          result (ledger/project world #'total-damage-dealt)]
      (is (= 50 result)))))

(deftest projection-skips-non-matching-events
  (testing "projection only folds its declared event-kind"
    (let [world      (-> (ecs/empty-world) evt/with-ledger)
          [world e1] (ecs/spawn world)
          world      (evt/dispatch world (->took-damage 1 #{e1} {:amount 10}))
          world      (evt/dispatch world (->died 2 #{e1} {:cause :poison}))
          world      (evt/dispatch world (->took-damage 3 #{e1} {:amount 5}))
          result     (ledger/project world #'total-damage-dealt)]
      (is (= 15 result)))))

;; ----- aggregate μ-specs ----------------------------------------------------

(defaggregate damage-log
  "Per-entity damage history."
  {:tracked [took-damage died]
   :init    (fn [] {})}
  [acc event]
  (let [eid (first (:entities event))]
    (update acc eid (fnil conj []) event)))

(deftest aggregate-snapshots-and-resumes
  (testing "checkpoint then replay from cursor is identical to full fold"
    (let [world      (-> (ecs/empty-world) evt/with-ledger)
          [world e1] (ecs/spawn world)
          world      (evt/dispatch world (->took-damage 1 #{e1} {:amount 10}))
          world      (evt/dispatch world (->took-damage 2 #{e1} {:amount 20}))
          snap       (ledger/checkpoint world #'damage-log)      ;; save after tick 2
          world      (evt/dispatch world (->took-damage 3 #{e1} {:amount 5}))
          ;; resume from snapshot — should not re-fold ticks 1 & 2
          resumed    (ledger/resume world snap #'damage-log)
          full       (ledger/project-all world #'damage-log)]
      (is (= full resumed))
      (is (= 3 (count (get resumed e1)))))))

(deftest aggregate-fast-forward
  (testing "fast-forward accumulates delta ticks only"
    (let [world      (-> (ecs/empty-world) evt/with-ledger)
          [world e1] (ecs/spawn world)
          world      (evt/dispatch world (->took-damage 1 #{e1} {:amount 5}))
          snap       (ledger/checkpoint world #'damage-log)
          world      (evt/dispatch world (->took-damage 2 #{e1} {:amount 5}))
          world      (evt/dispatch world (->took-damage 3 #{e1} {:amount 5}))
          world      (evt/dispatch world (->took-damage 4 #{e1} {:amount 5}))
          resumed    (ledger/resume world snap #'damage-log)]
      ;; Only 3 new events should have been folded
      (is (= 4 (count (get resumed e1)))))))
```

## `domain/ecs/ledger.clj`

The ledger is an append-only vector of events. A `cursor` is an integer index into it. A `Checkpoint` is `{:cursor N :value V}`.

```clojure
(ns domain.ecs.ledger
  "Append-only event ledger with named projection and aggregate support.
   All operations are pure — no atoms, no side effects."
  (:require
    [domain.ecs.event :as evt]))

;; ---- Data shapes -----------------------------------------------------------

(defrecord Ledger
  [events    ;; vector of event maps, append-only
   cursor])  ;; integer: index of next unread position (monotone)

(defn empty-ledger
  []
  (->Ledger [] 0))

(defrecord Checkpoint
  [cursor    ;; ledger index at the point of checkpointing
   value])   ;; materialized aggregate value at cursor

(defn append
  "Append a single event to the ledger. Returns a new Ledger."
  [^Ledger ledger event]
  (->Ledger (conj (:events ledger) event)
            (:cursor ledger)))

(defn events-since
  "All events at or after `cursor`."
  [^Ledger ledger cursor]
  (subvec (:events ledger) cursor))

(defn events-of-kind
  "Filter events matching one or more `kinds` (set of keywords)."
  [events kinds]
  (filterv #(contains? kinds (:kind %)) events))

;; ---- Projection runtime ----------------------------------------------------

(defn project
  "Fold a named projection var over every matching event in the ledger.
   Uses :projection/init, :projection/event-kind, and the function body."
  [world projection-var]
  (let [{:keys [projection/event-kind
                projection/init]} (meta projection-var)
        f                         @projection-var
        ledger                    (:ledger world)
        events                    (events-of-kind (:events ledger)
                                                  #{event-kind})]
    (reduce f (init) events)))

(defn project-all
  "Same as project but for aggregates that track multiple event kinds."
  [world aggregate-var]
  (let [{:keys [aggregate/tracked
                aggregate/init]}  (meta aggregate-var)
        f                         @aggregate-var
        ledger                    (:ledger world)
        events                    (events-of-kind (:events ledger)
                                                  (set tracked))]
    (reduce f (init) events)))

;; ---- Checkpoint / resume ---------------------------------------------------

(defn checkpoint
  "Materialize an aggregate up to the current ledger cursor.
   Returns a Checkpoint."
  [world aggregate-var]
  (let [value  (project-all world aggregate-var)
        cursor (count (:events (:ledger world)))]
    (->Checkpoint cursor value)))

(defn resume
  "Fold an aggregate from a Checkpoint forward to the current ledger tail.
   Only events appended *after* the checkpoint cursor are folded."
  [world ^Checkpoint snap aggregate-var]
  (let [{:keys [aggregate/tracked]} (meta aggregate-var)
        f      @aggregate-var
        ledger (:ledger world)
        delta  (-> (events-since ledger (:cursor snap))
                   (events-of-kind (set tracked)))]
    (reduce f (:value snap) delta)))
```

## DSL macros — `defprojection` + `defaggregate`

These live in `domain.ecs.dsl` alongside the previous macros. Expand into vars carrying their runtime metadata so `ledger/project` and `ledger/resume` can find everything they need from the var itself.

```clojure
(defmacro defprojection
  "Define a named event-log projection.
   Folds a single event-kind into an accumulator.

   Usage:
     (defprojection my-proj
       \"Docstring\"
       my-event-kind
       {:init 0}
       [acc event]
       (+ acc (get-in event [:payload :amount])))"
  [name doc event-kind {:keys [init]} [acc-sym event-sym] & body]
  `(defn ^{:doc ~doc
           :ecs/kind      :projection
           :projection/event-kind ~event-kind
           :projection/init       (fn [] ~init)}
     ~name
     [~acc-sym ~event-sym]
     ~@body))

(defmacro defaggregate
  "Define a named aggregate over multiple tracked event kinds.
   Supports checkpoint/resume for incremental fast-forward.

   Usage:
     (defaggregate my-agg
       \"Docstring\"
       {:tracked [event-kind-a event-kind-b]
        :init    (fn [] {})}
       [acc event]
       ...)"
  [name doc {:keys [tracked init]} [acc-sym event-sym] & body]
  `(defn ^{:doc ~doc
           :ecs/kind       :aggregate
           :aggregate/tracked (quote ~tracked)
           :aggregate/init    ~init}
     ~name
     [~acc-sym ~event-sym]
     ~@body))
```

## `domain/ecs/event.clj`

The minimal event runtime the ledger macros assume:

```clojure
(ns domain.ecs.event
  "Minimal event dispatch and handler registry.
   All state lives in the world map. No global atoms.")

(defn ->event
  "Construct a raw event map."
  [{:keys [tick kind entities payload cause]}]
  {:tick     (or tick 0)
   :kind     kind
   :entities (set entities)
   :payload  (or payload {})
   :cause    cause})

(defn with-ledger
  "Add an empty ledger to a world map."
  [world]
  (assoc world
    :ledger   {:events [] :cursor 0}
    :handlers {}))

(defn with-handlers
  "Alias — no-op if ledger already present; used for test legibility."
  [world]
  (update world :handlers (fnil identity {})))

(defn register-handler
  "Register a pure handler fn for a given event kind."
  [world kind f]
  (update world :handlers assoc kind f))

(defn dispatch
  "Append an event to the ledger and run any registered handler.
   Returns the updated world."
  [world event]
  (let [world'  (update-in world [:ledger :events] conj event)
        handler (get-in world' [:handlers (:kind event)])]
    (if handler
      (handler world' event)
      world')))
```

## What this unlocks

With `defprojection`, `defaggregate`, `checkpoint`, and `resume` in place, the off-screen simulation loop can do this:

```clojure
;; Regional zone LOD tick — called every 1 s
(defn lod-tick-regional [world region-id]
  (let [snap      (ledger/checkpoint world #'damage-log)   ;; save cursor
        world'    (run-regional-systems world region-id)]  ;; append N events
    ;; resume from snap — only delta ticks folded, O(delta) not O(ledger)
    (assoc world' :regional-cache
           (ledger/resume world' snap #'damage-log))))
```

And for fast-forward on zone entry (the "smoke still rising" effect):

```clojure
(defn catch-up [world region-id last-visited-tick]
  ;; Replay from a checkpoint stored at last-visited-tick, not from genesis
  (let [snap (get-in world [:region-checkpoints region-id])]
    (if snap
      (ledger/resume world snap #'civilization-history)
      (ledger/project-all world #'civilization-history))))
```
