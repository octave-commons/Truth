Yes — this is the right layer to formalize now. The project brief already makes two constraints explicit: cross-boundary definitions should name Malli validators, and the event log should capture significant off-screen occurrences rather than every continuous simulation delta [^13_1].

So the DSL should stay **thin**: macros declare component keys, event constructors, system queries, and reaction bindings; runtime stays plain data plus pure functions.

## `law/ecs_dsl.clj`

Start with the contracts. This gives the macros a lawful shape and keeps the boundary in `law/`, not hidden inside expansion magic.

```clojure
(ns law.ecs-dsl
  "Malli contracts for the ECS + event ledger DSL."
  (:require
    [malli.core :as m]))

(def SimpleName
  [:fn {:error/message "Expected a simple symbol"}
   simple-symbol?])

(def DocString
  [:and string? [:fn {:error/message "Docstring must be non-blank"}
                 #(not (clojure.string/blank? %))]])

(def ComponentRef
  [:or keyword? SimpleName])

(def ComponentDef
  [:map
   [:name SimpleName]
   [:doc DocString]
   [:schema any?]
   [:key keyword?]])

(def EventOptions
  [:map
   [:entity-count {:optional true} pos-int?]
   [:reversible? {:optional true} boolean?]])

(def EventDef
  [:map
   [:name SimpleName]
   [:doc DocString]
   [:payload-schema any?]
   [:key keyword?]
   [:options EventOptions]])

(def SystemDef
  [:map
   [:name SimpleName]
   [:doc DocString]
   [:query [:vector ComponentRef]]])

(def validate-component-def
  (m/validator ComponentDef))

(def validate-event-def
  (m/validator EventDef))

(def validate-system-def
  (m/validator SystemDef))

(defn assert-component-def!
  "Throw if a component DSL form is invalid."
  [x]
  (when-not (validate-component-def x)
    (throw (ex-info "Invalid component definition"
                    {:kind ::invalid-component-def
                     :value x})))
  x)

(defn assert-event-def!
  "Throw if an event DSL form is invalid."
  [x]
  (when-not (validate-event-def x)
    (throw (ex-info "Invalid event definition"
                    {:kind ::invalid-event-def
                     :value x})))
  x)

(defn assert-system-def!
  "Throw if a system DSL form is invalid."
  [x]
  (when-not (validate-system-def x)
    (throw (ex-info "Invalid system definition"
                    {:kind ::invalid-system-def
                     :value x})))
  x)
```


## `test/domain/ecs/dsl_test.clj`

These are the first μ-specs. They prove the DSL does four things: define lawful component vars, define lawful event constructors, define query-driven systems, and bind reactions to the ledger path.

```clojure
(ns domain.ecs.dsl-test
  (:require
    [clojure.test :refer [deftest is testing]]
    [domain.ecs.core :as ecs]
    [domain.ecs.event :as evt]
    [domain.ecs.dsl :refer [defcomponent defevent defsystem defreaction
                            install-reaction query-rows]]
    [malli.core :as m]))

(defcomponent position
  "Cartesian position."
  [:vector {:min 3 :max 3} :double])

(defcomponent velocity
  "Cartesian velocity."
  [:vector {:min 3 :max 3} :double])

(defevent collision
  "Discrete collision event between two entities."
  [:map
   [:normal [:vector {:min 3 :max 3} :double]]
   [:depth :double]]
  {:entity-count 2
   :reversible? true})

(defreaction mark-collided
  "Marks all participating entities as collided."
  collision
  [world event]
  (reduce (fn [w eid]
            (ecs/put-component w eid :component/collided? true))
          world
          (:entities event)))

(defsystem zero-velocity
  "Set queried velocities to zero."
  {:query [velocity]}
  [world rows]
  (reduce (fn [w [eid _components]]
            (ecs/put-component w eid velocity [0.0 0.0 0.0]))
          world
          rows))

(deftest component-dsl-defines-key-and-validator
  (testing "defcomponent creates a keyword var and schema validator"
    (is (= :component/position position))
    (is (position? [1.0 2.0 3.0]))
    (is (not (position? [1.0 2.0])))))

(deftest event-dsl-defines-constructor
  (testing "defevent creates a checked constructor"
    (let [event (->collision 7 #{:a :b} {:normal [1.0 0.0 0.0]
                                         :depth  0.25})]
      (is (= :event/collision (:kind event)))
      (is (= 7 (:tick event)))
      (is (= #{:a :b} (:entities event)))
      (is (= 0.25 (get-in event [:payload :depth]))))))

(deftest system-dsl-queries-by-component
  (testing "defsystem receives only matching rows"
    (let [[world e1] (ecs/spawn (ecs/empty-world))
          [world e2] (ecs/spawn world)
          world      (ecs/put-component world e1 velocity [4.0 5.0 6.0])
          world'     (zero-velocity world)]
      (is (= [0.0 0.0 0.0] (ecs/get-component world' e1 velocity)))
      (is (nil? (ecs/get-component world' e2 velocity))))))

(deftest reaction-dsl-installs-on-ledger-path
  (testing "reaction is installable from var metadata"
    (let [[world e1] (ecs/spawn (-> (ecs/empty-world)
                                    evt/with-ledger
                                    evt/with-handlers))
          [world e2] (ecs/spawn world)
          world      (install-reaction world #'mark-collided)
          world'     (evt/dispatch world
                                   (->collision 0 #{e1 e2}
                                                {:normal [1.0 0.0 0.0]
                                                 :depth 0.5}))]
      (is (= true (ecs/get-component world' e1 :component/collided?)))
      (is (= true (ecs/get-component world' e2 :component/collided?)))
      (is (= 1 (count (:ledger world')))))))
```


## `domain/ecs/dsl.clj`

Now the minimal implementation. The macros mostly generate vars, validators, constructors, and metadata. The runtime helpers do the actual work and remain boring on purpose.

```clojure
(ns domain.ecs.dsl
  "Thin ECS + event ledger DSL.
   Macros declare component keys, event constructors, systems, and reactions.
   Runtime stays plain ECS maps and pure functions."
  (:require
    [clojure.string :as str]
    [malli.core :as m]
    [law.ecs-dsl :as law]
    [domain.ecs.core :as ecs]
    [domain.ecs.event :as evt]))

(defn query-rows
  "Return [eid {component-key value ...}] rows for every entity
   that has all requested component keys."
  [world component-keys]
  (mapv (fn [eid]
          [eid (into {}
                     (map (fn [k] [k (ecs/get-component world eid k)]))
                     component-keys)])
        (apply ecs/entities-with world component-keys)))

(defn install-reaction
  "Install a reaction var using its :event/kind metadata."
  [world reaction-var]
  (let [kind (:event/kind (meta reaction-var))]
    (when-not kind
      (throw (ex-info "Reaction var is missing :event/kind metadata"
                      {:kind ::missing-event-kind
                       :var reaction-var})))
    (evt/register-handler world kind @reaction-var)))

(defn- component-key
  [sym]
  (keyword "component" (name sym)))

(defn- event-key
  [sym]
  (keyword "event" (name sym)))

(defmacro defcomponent
  [name doc schema]
  (let [k             (component-key name)
        schema-sym    (symbol (str name "-schema"))
        validator-sym (symbol (str name "-validator"))
        pred-sym      (symbol (str name "?"))]
    (law/assert-component-def!
      {:name name
       :doc doc
       :schema schema
       :key k})
    `(do
       (def ~schema-sym ~schema)
       (def ~validator-sym (m/validator ~schema-sym))
       (def ^{:doc ~doc
              :ecs/kind :component
              :ecs/key ~k
              :ecs/schema '~schema-sym}
         ~name
         ~k)
       (defn ~pred-sym
         ~doc
         [value#]
         (~validator-sym value#)))))

(defmacro defevent
  [name doc payload-schema options]
  (let [k             (event-key name)
        schema-sym    (symbol (str name "-payload-schema"))
        validator-sym (symbol (str name "-payload-validator"))
        ctor-sym      (symbol (str "->" name))
        emit-sym      (symbol (str "emit-" name))
        entity-count  (:entity-count options)
        reversible?   (:reversible? options false)]
    (law/assert-event-def!
      {:name name
       :doc doc
       :payload-schema payload-schema
       :key k
       :options options})
    `(do
       (def ~schema-sym ~payload-schema)
       (def ~validator-sym (m/validator ~schema-sym))
       (def ^{:doc ~doc
              :ecs/kind :event
              :event/key ~k
              :event/payload-schema '~schema-sym
              :event/entity-count ~entity-count
              :event/reversible? ~reversible?}
         ~name
         ~k)
       (defn ~ctor-sym
         ~doc
         ([tick# entities# payload#]
          (~ctor-sym tick# entities# payload# nil))
         ([tick# entities# payload# cause#]
          (let [entities-set# (set entities#)]
            ~(when entity-count
               `(when-not (= ~entity-count (count entities-set#))
                  (throw (ex-info "Invalid entity count for event"
                                  {:kind ::invalid-entity-count
                                   :event ~k
                                   :expected ~entity-count
                                   :actual (count entities-set#)}))))
            (when-not (~validator-sym payload#)
              (throw (ex-info "Invalid event payload"
                              {:kind ::invalid-event-payload
                               :event ~k
                               :payload payload#})))
            (evt/->event {:tick tick#
                          :kind ~k
                          :entities entities-set#
                          :payload payload#
                          :cause cause#}))))
       (defn ~emit-sym
         ~doc
         ([world# entities# payload#]
          (~emit-sym world# entities# payload# nil))
         ([world# entities# payload# cause#]
          (evt/dispatch world#
                        (~ctor-sym (:tick world#)
                                   entities#
                                   payload#
                                   cause#)))))))

(defmacro defsystem
  [name doc {:keys [query] :as opts} [world-sym rows-sym] & body]
  (law/assert-system-def!
    {:name name
     :doc doc
     :query query})
  `(defn ^{:doc ~doc
           :ecs/kind :system
           :ecs/query '~query}
     ~name
     [~world-sym]
     (let [~rows-sym (query-rows ~world-sym [~@query])]
       ~@body)))

(defmacro defreaction
  [name doc event-kind [world-sym event-sym] & body]
  `(defn ^{:doc ~doc
           :ecs/kind :reaction
           :event/kind ~event-kind}
     ~name
     [~world-sym ~event-sym]
     ~@body))
```


## Example use

This is the shape I’d actually build around collisions. It keeps the declaration surface compact while leaving the orbital math and collision response in ordinary functions.

```clojure
(ns domain.physics.collision
  (:require
    [domain.ecs.core :as ecs]
    [domain.ecs.dsl :refer [defcomponent defevent defsystem defreaction]]
    [shape.spatial :as sp]))

(defcomponent position
  "Cartesian position."
  [:vector {:min 3 :max 3} :double])

(defcomponent radius
  "Bounding radius."
  :double)

(defcomponent velocity
  "Cartesian velocity."
  [:vector {:min 3 :max 3} :double])

(defevent collision
  "Discrete overlap between two entities."
  [:map
   [:normal [:vector {:min 3 :max 3} :double]]
   [:depth :double]]
  {:entity-count 2
   :reversible? true})

(defsystem detect-collisions
  "Emit collision events for overlapping sphere pairs."
  {:query [position radius]}
  [world rows]
  (reduce
    (fn [w [[ea ca] [eb cb]]]
      (let [pa (get ca position)
            pb (get cb position)
            ra (get ca radius)
            rb (get cb radius)
            d  (sp/dist pa pb)]
        (if (<= d (+ ra rb))
          (emit-collision w #{ea eb}
                          {:normal (if (zero? d)
                                     [1.0 0.0 0.0]
                                     (sp/v* (sp/v- pb pa) (/ 1.0 d)))
                           :depth  (- (+ ra rb) d)})
          w)))
    world
    (for [a rows
          b rows
          :when (neg? (compare (first a) (first b)))]
      [a b])))

(defreaction resolve-collision
  "Simple velocity inversion placeholder."
  collision
  [world event]
  (reduce
    (fn [w eid]
      (update-in w [:components velocity eid]
                 (fn [[x y z]]
                   [(- x) (- y) (- z)])))
    world
    (:entities event)))
```

This gets you a real DSL spine:

- `defcomponent` for canonical ECS vocabulary.
- `defevent` for lawful, ledger-ready event constructors.
- `defsystem` for query-driven world transforms.
- `defreaction` for event responses installable from metadata.

The next worthwhile move is a second macro layer on top of this: `defaggregate` for snapshot/materialized views and `defprojection` for ledger-derived caches, so fast-forward/rewind can reuse named projections instead of replaying everything from genesis.
