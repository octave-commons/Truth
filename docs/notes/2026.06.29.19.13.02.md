 Frames

 ### 1. Coherence is your "life bar" — but it degrades gently,
 not fatally

 The observer starts at 0.8 coherence (max 1.0). Every frame, two
 forces fight:

 ```
   drain  = 0.003 × focus-intensity     ;; focusing costs
 coherence
   regen  = 0.003 × (1 - focus-intensity) ;; relaxing restores it
 ```

 At default focus (0.5): drain ≈ regen — the bar holds steady.
 At max focus (1.0): drain = 0.003/frame, regen = 0 → bar empties
 in ~7 seconds.
 At min focus (0.1): drain = 0.0003, regen = 0.0027 → bar refills
 in ~6 seconds.

 This is the core tension: to see more detail, you burn your own
 existence.

 When coherence drops below thresholds, you enter decoherence
 states that the renderer communicates through color:

 ┌──────────────────┬───────────┬───────────────┐
 │ State            │ Coherence │ Reticle Color │
 ├──────────────────┼───────────┼───────────────┤
 │ :highly-coherent │ > 0.8     │ teal-green    │
 ├──────────────────┼───────────┼───────────────┤
 │ :coherent        │ > 0.5     │ cyan          │
 ├──────────────────┼───────────┼───────────────┤
 │ :wavering        │ > 0.2     │ yellow        │
 ├──────────────────┼───────────┼───────────────┤
 │ :fading          │ > 0.05    │ orange        │
 ├──────────────────┼───────────┼───────────────┤
 │ :dissolved       │ ≤ 0.05    │ dark red      │
 └──────────────────┴───────────┴───────────────┘

 Below 0.05, can-interact? returns false — you can no longer
 influence the world. You become a passive observer. This is the
 "soft death" — no game-over screen, just a fading into the
 background.

 ### 2. How it's wired to the mouse — the "attention as
 computation" loop

 The mouse cursor drives your focus position in world space.
 Every frame in window.clj:

 ```clojure
   ;; passive, free: the spark's attention follows the mouse
   (inspect/cursor->world cam cur-sx cur-sy fb-w fb-h scale)
   → (player/set-focus observer world-point focus-radius
 focus-intensity)
 ```

 Then coherence and focus-intensity combine into the observation
 effect:

 ```clojure
   (defn observation-effect [{:keys [coherence focus-intensity]}]
     (* coherence focus-intensity))
 ```

 This single product controls three things:

 1. Collapse radius — focus-radius × coherence — the zone where
 your attention "resolves reality." Bodies inside this radius get
 a gentle pull toward your focus point.
 2. Influence strength — coherence × focus-intensity × 0.1 — the
 magnitude of the acceleration nudge. At full coherence and
 focus, you impart ~0.1 × ref-speed per tick. At dissolved
 coherence, zero.
 3. Visual feedback — the spark size scales with focus-intensity,
 the reticle ring color shifts with coherence state, and the HUD
 bar (bottom-left) shows fill fraction tinted by decoherence
 state.

 The pull-toward-focus is dt-robust — it targets a bounded Δv
 regardless of simulation timestep, so a Myr-scale step doesn't
 blow past c. The formula:

 ```clojure
   accel = pull × (ref-speed / max(1, dt))
   ;; so v += pull × ref-speed, independent of dt
 ```

 ### 3. Coherence vs. Agency — two distinct resources

 This is a critical design distinction your code makes explicit:

 ┌───────────┬───────────────┬───────────────┬──────────────────┐
 │ Resource  │ What it is    │ How you get   │ What it spends   │
 │           │               │ it            │ on               │
 ├───────────┼───────────────┼───────────────┼──────────────────┤
 │ Coherence │ Your          │ Passive regen │ Nothing directly │
 │           │ life/clarity  │ when relaxed; │ — it gates your  │
 │           │               │ drains under  │ capacity to      │
 │           │               │ focus         │ influence        │
 ├───────────┼───────────────┼───────────────┼──────────────────┤
 │ Agency    │ Spendable     │ Witnessing    │ Paid             │
 │           │ action quanta │ threshold     │ interventions:   │
 │           │               │ events        │ warp wells,      │
 │           │               │ (ignition:    │ repulsors, heat  │
 │           │               │ +25, planet:  │ sources/sinks    │
 │           │               │ +10, life:    │ (15 each)        │
 │           │               │ +50)          │                  │
 └───────────┴───────────────┴───────────────┴──────────────────┘

 Coherence is the passive resource — it determines how much your
 mouse matters. Agency is the active resource — it determines
 what actions you can take. You earn agency by watching the
 universe do interesting things. You spend it to place forces or
 thermal interventions.

 From domain/player.clj:

 ```clojure
   ;; `agency` is the SPENDABLE action currency (influence
 quanta), distinct from
   ;; coherence (the spark's life/clarity). Witnessing reality
 crystallize — every
   ;; classifier transition — releases quanta the observer banks;
 paid actions
   ;; (warp/heat/transmute) spend them. Passive observation
 (looking, hovering,
   ;; moving) costs nothing and earns nothing. Starts empty: you
 must witness to act.
   :agency 0.0
 ```

 ### 4. The mouse-influence pipeline in full

 Here's the complete chain from mouse movement to physical
 effect, each frame:

 1. Cursor → world point (window.clj): Ray-cast from camera
 through cursor pixel to the simulation plane.
 2. Focus update (player/set-focus): The observer's
 :focus-position tracks the cursor. Free, no cost.
 3. Observer system (observer-system in player.clj): Each tick:
     - Reads new events from the ECS event ledger
     - Applies coherence drain/regen/gains
     - Grants agency for witnessed events
     - Caches observation-effect, collapse-radius,
 observation-note
     - Calls apply-observer-influence — writes
 :component/accel.observer onto every body inside the collapse
 radius
 4. Motion integrator (domain/orbital/system.clj): Sums ALL
 acceleration channels — gravity, pressure, Lorentz, observer,
 warp — and advances velocity/position.
 5. Renderer (infra/render.clj): Reads the cached observation
 state for:
     - Reticle ring color (tinted by decoherence state)
     - Spark size (scaled by focus-intensity)
     - HUD coherence bar fill + color
     - Observation note text ("You are fading..." / "Light. For
 the first time, light.")
     - Event notifications ("A star ignites! +25 quanta")

 ### 5. The intended experience

 The design doc makes the emotional arc explicit:

 │ "The player should feel that they did not switch games. The
 │ universe merely cooled, slowed, and became more articulate."

 Coherence creates a rhythm:
 - High focus → you see detail, bodies drift toward your gaze,
 but you're burning yourself
 - Low focus → you recover coherence, the world goes statistical,
 you drift
 - Threshold events (ignition, planet formation) → burst of
 coherence + agency → renewed capacity
 - Dying system → no events → coherence drains with no recovery →
 time slips → you drift to another nebula

 The mouse is your attention. Coherence is how long you can
 sustain it. Agency is what you earned by paying attention.

 Countermoves

 1. Coherence is not yet coupled to the dual-representation LOD
 system. The spec
 (docs/specs/phase0-player-focus-and-dual-representation.md)
 calls for coherence cost to scale with the number of particles
 promoted into the immediate zone — more resolved matter = more
 drain. Currently it's purely focus-intensity based.
 2. The narrator mood system
 (docs/specs/phase0-narrator-presence.md) is designed to shift
 based on coherence (mood drifts toward :dread below 0.2) but
 isn't implemented yet.
 3. Time-slip (time-slip-threshold?) exists as a function but
 isn't wired into the pacing system — low coherence + low
 complexity should cause the sim clock to jump forward.
